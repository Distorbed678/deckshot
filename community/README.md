# Community maps and custom cards

Everything here shows up in the game's Community browser. To add yours, use **Submit** in the
browser. It opens GitHub with your file filled in, then you confirm it as a pull request. Once a
pull request is merged, the map or card appears for everyone.

Files go in `maps/` or `cards/` and are the plain text the game saves. File names may only use
letters, numbers, `-` and `_`, and must end in `.txt`. Each file must be under 64 KB. A check runs on
every pull request to make sure the file loads.
